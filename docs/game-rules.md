# Wild Count ゲームルール仕様

## 基本情報

- プレイヤー数：2〜10人
- 初期ライフ：3（デフォルト、設定可能）
- 勝利条件：最後の1人まで生き残る

## カード

### 通常カード (NUMBER)
- 値：負の値を含む整数（具体的な範囲はdeck.tsで定義）

### 特殊カード (SPECIAL)
- **DOUBLE**：合計値を倍化（複数枚で累積）
- **MAX_TO_ZERO**：そのラウンドの正の最大値を0にする（同値はすべて0）

## ラウンド進行

1. 生存プレイヤーに1枚ずつカードを配布
2. 宣言フェーズ（席順）
3. チャレンジ（直前の宣言者に対して）
4. 全カード公開 & 合計値計算
5. 勝敗判定 → 敗者のライフ −1
6. 生存が1人ならゲーム終了、そうでなければ次のラウンド

## 合計値計算順序（確定）

1. ラウンド対象カードを収集
2. **MAX_TO_ZERO** 効果を適用  
   （正の最大値を0に。同値が複数ある場合はすべて0）
3. 通常数値カードの合計（負の値もそのまま加算）
4. **DOUBLE** 効果を適用（倍化カードの枚数分累積）
5. 最終合計値確定

**計算結果**は `CalculationResult` 型で過程も記録（結果画面表示用）

## チャレンジ判定（確定）

```ts
if (actualTotal >= bid) {
  // 宣言側の勝ち（同値も宣言側勝利）
  loser = "CHALLENGER";
} else {
  loser = "BIDDER";
}
```

## Phase 0 で確定した細部

実装: `src/domain/game/`（純粋関数。UI / Worker 非依存）

| 項目 | 採用 |
|------|------|
| パス | **なし**（MVP は宣言 or チャレンジのみ） |
| 初手宣言の下限 | **0**（整数）。以降は現在宣言より大きい整数 |
| 手番 | 生存プレイヤーの席順（seatIndex 昇順、ラップ） |
| チャレンジ対象 | **直前の宣言者** |
| 次ラウンド開始席 | 直前チャレンジの敗者（脱落済みなら次の生存席） |
| 合計値0化カード | **未採用**（card-design に無し。design-overview の即0ルールは保留） |
| 引き直し `?` | 配札時に捨てて再ドロー（手札に残さない） |
| 捨て札ミックス0 | 数値 **0** として合計。配札後に捨て札を山へ戻してシャッフル |
| 山札切れ | 捨て札を戻してシャッフル。それでも足りなければエラー |
| デッキ枚数 | デフォルトは card-design 表の合計 **36**（`STANDARD_DECK`）。構成は `DeckComposition` で差し替え可能（将来ルーム作成時に選択） |
| デッキ拡張 | プリセット追加は `DECK_PRESETS`、カスタムは `defineDeckComposition` / オブジェクト指定 |
