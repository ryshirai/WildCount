# Wild Count ゲームルール仕様

## 基本情報

- プレイヤー数：2〜10人
- 初期ライフ：3（デフォルト、設定可能）
- 勝利条件：最後の1人まで生き残る

## カード

### 通常カード (NUMBER)
- 値：負の値を含む整数（具体的な範囲はdeck.tsで定義）

### 特殊カード (SPECIAL)
- **DOUBLE**：合計値を倍化（複数枚で累積）
- **MAX_TO_ZERO**：そのラウンドの正の最大値を0にする（同値はすべて0）

## ラウンド進行

1. 生存プレイヤーに1枚ずつカードを配布
2. 宣言フェーズ（順番に宣言またはパス）
3. チャレンジ or 全員宣言終了
4. 全カード公開 & 合計値計算
5. 勝敗判定 → ライフ増減
6. 次のラウンド

## 合計値計算順序（確定）

1. ラウンド対象カードを収集
2. **MAX_TO_ZERO** 効果を適用  
   （正の最大値を0に。同値が複数ある場合はすべて0）
3. 通常数値カードの合計（負の値もそのまま加算）
4. **DOUBLE** 効果を適用（倍化カードの枚数分累積）
5. 最終合計値確定

**計算結果**は `CalculationResult` 型で過程も記録（結果画面表示用）
