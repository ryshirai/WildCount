# Wild Count ゲームルール仕様

## 基本情報

- プレイヤー数：2〜10人
- 初期ライフ：3（デフォルト、設定可能）
- 勝利条件（ルーム設定で変更可）:
  - **一人脱落で終了**（デフォルト）: 誰か1人でもライフが0になったら試合終了
  - **勝ち残り**: 最後の1人が残るまで続ける

## カード

### 通常カード (NUMBER)
- 値：負の値を含む整数（具体的な範囲はdeck.tsで定義）

### 特殊カード (SPECIAL)
- **DOUBLE**：合計値を倍化（複数枚で累積）
- **MAX_TO_ZERO**：そのラウンドの正の最大値を0にする（同値はすべて0）

## カードの見え方（インディアンポーカー / コヨーテ式）

- **自分の手札は見えない**（額に貼るイメージ。ローカル視点でも常に `?`）
- **他プレイヤーのカードは見える**（それを材料に合計を推理して宣言する）
- チャレンジ後の結果画面で、自分のカードを含む**全カードを公開**する

> Worker 接続時は「自分のカードをサーバーから送らない」（`docs/design-overview.md` §5）と整合する。
> ローカルデモではエンジン state に全員の hands があるが、UI は上記視点にマップする。

## ラウンド進行

1. 生存プレイヤーに1枚ずつカードを配布（自分以外は表向き）
2. 宣言フェーズ（席順）
3. チャレンジ（直前の宣言者に対して）
4. 全カード公開 & 合計値計算
5. 勝敗判定 → 敗者のライフ −1
6. 勝利条件に応じて終了判定
   - 一人脱落で終了: ライフ0のプレイヤーがいればゲーム終了（生存が複数でも可）
   - 勝ち残り: 生存が1人ならゲーム終了、そうでなければ次のラウンド

## 合計値計算順序（確定）

1. ラウンド対象カードを収集
2. **MAX_TO_ZERO** 効果を適用  
   （正の最大値を0に。同値が複数ある場合はすべて0）
3. 通常数値カードの合計（負の値もそのまま加算）
4. **DOUBLE** 効果を適用（倍化カードの枚数分累積）
5. 最終合計値確定

**計算結果**は `CalculationResult` 型で過程も記録（結果画面表示用）

## チャレンジ判定（確定）

```ts
if (actualTotal >= bid) {
  // 宣言側の勝ち（同値も宣言側勝利）
  loser = "CHALLENGER";
} else {
  loser = "BIDDER";
}
```

## Phase 0 で確定した細部

実装: `src/domain/game/`（純粋関数。UI / Worker 非依存）

| 項目 | 採用 |
|------|------|
| パス | **なし**（MVP は宣言 or チャレンジのみ） |
| 初手宣言の下限 | **1**（整数）。以降は現在宣言より大きい整数 |
| 手番 | 生存プレイヤーの席順（seatIndex 昇順、ラップ） |
| 席順 | **毎ラウンド開始時に席替え**（seatIndex をシャッフル） |
| 第1ラウンド開始席 | **ランダム**（ホスト／参加順固定ではない） |
| チャレンジ対象 | **直前の宣言者** |
| 次ラウンド開始席 | 直前チャレンジの敗者（脱落済みなら生存者からランダム）。席替え後の seat で開始 |
| 合計値0化カード | **未採用**（card-design に無し。design-overview の即0ルールは保留） |
| 引き直し `?` | 配札時に捨てて再ドロー（手札に残さない） |
| 捨て札ミックス0 | 数値 **0** として合計。配札後に捨て札を山へ戻してシャッフル |
| 山札切れ | 捨て札を戻してシャッフル。それでも足りなければエラー |
| デッキ枚数 | デフォルトは card-design 表の合計 **36**（`STANDARD_DECK`）。構成は `DeckComposition` で差し替え可能 |
| デッキ拡張 | プリセット追加は `DECK_PRESETS`、カスタムは `defineDeckComposition` / オブジェクト指定 |
| ルーム山札 | オンラインロビーで **ホスト** が `set_deck` により枚数を変更可能（10〜120 枚）。参加者全員の `PlayerView.deck` に同期。`start` 時にその構成で配札 |

## エクストラルール（任意）

ホストが ON/OFF する任意バリアント。**デフォルト OFF**（上記 MVP と同一）。

| 要素 | 要約 |
|------|------|
| セイム | 特殊能力。宣言維持のパス相当。個人枠 1 消費。直前がセイムなら連続不可 |
| チェンジ | 特殊能力。直前宣言者に付け直し強制。**同じ数字不可**。個人枠 1 消費 |
| リバース | 特殊能力（宣言に乗せる）。進行方向反転 |
| ショット | 特殊能力。次手番を自分以外の生存者に指名 |
| ドロー1 | 特殊能力。自分以外に +1 枚。**ラウンド全体で 1 回** |
| ダブル | 特殊能力。次手番者がチャレンジしたら敗者ライフ −2 |

**1/2 カード**はエクストラではなく **山札構成**（`specials.half` / ロビー山札カスタム）で枚数を決める。倍率 ÷2（×2 と相殺可）、端数は 0 方向切り捨て。

共通: **特殊能力は 1 人 1 ラウンド 1 回**（セイム・チェンジ・リバース・ショット・ドロー・ダブルで枠を共有。次ラウンドで復活）。宣言に乗せる能力は 1 宣言につき 1 つ。
