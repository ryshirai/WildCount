# Wild Count 設計概要

リアルタイム数字推理・ブラフゲーム「Wild Count」のWeb版設計書です。

## 1. 概要

### 目的

複数人でリアルタイムに遊べるCoyote系数字推理・ブラフゲームを、ブラウザベースのWebアプリとして提供する。

- 最大10人同時プレイ
- iPhone / Android / PCブラウザから同じURLで参加可能
- PWA対応（ホーム画面追加可能）

### 基本方針

- レスポンシブWebアプリ（ネイティブアプリは作らない）
- リアルタイム通信：WebSocket
- ゲーム状態の正本は**サーバー（Durable Object）**
- 1ルーム = 1 Durable Object
- ゲームエンジンはUI・通信から完全に分離（純粋関数）
- 身内向け招待制・無料運用を前提
- 公式素材は一切使用せず、オリジナルで構成

## 2. 技術構成

**Frontend**

- Vue 3 + TypeScript + Vite + Pinia + Vue Router
- Tailwind CSS（またはCSS Modules）
- vite-plugin-pwa

**Backend**

- Cloudflare Workers
- Durable Objects（WebSocket Hibernation）
- SQLite-backed Storage（MVPではD1未使用）

## 3. Phase 0：ゲームルール & エンジン確定（最優先）

### 特殊カード計算順序（MVP採用ルール）

1. ラウンド対象カードを収集
2. **合計値0化カード**の有無を確認（最優先）
3. 最大値0化効果を適用
4. 数値カードを合計
5. 倍化効果を適用
6. 最終合計値確定

**重要ルール**:

- 合計値0化カードが1枚でもあれば即`0`（他の効果無視）
- 最大値0化：正の最大値を0に（同値はすべて）
- 倍化：累積（2枚で×4）
- 負の合計値も許可

### チャレンジ判定

- `実際の合計値 >= 宣言値` → **宣言側の勝ち**
- 同値の場合も宣言側勝利

### 山札切れ時

- 捨て札を戻してシャッフル
- それでも足りなければ設定エラー

### ゲームエンジン要件

- `src/domain/game/` に純粋関数として実装
- `RandomSource`注入でテスト容易に
- 10,000ゲーム以上のシミュレーションで検証

詳細は `docs/game-rules.md` を参照。

## 4. ルーム・プレイヤー設計

- ルームコード：8文字（見間違いにくい文字のみ）
- ホスト自動移譲：切断60秒猶予 → 最長参加者に移譲
- 再接続：`localStorage` + resumeToken + 完全スナップショット

## 5. 状態管理・通信

- すべての操作に `actionId` + `expectedRevision`
- プレイヤー別ビュー生成（`createPlayerView`）
- 自分のカードは**サーバーから送信しない**

## 6. UI・対応

- PC：10人グリッドレイアウト
- スマホ：カルーセル + 下部固定操作エリア
- 現在手番強調 + 「あなたまであとX人」表示

## 7. テスト戦略

- **単体**：エンジン純粋関数
- **シミュレーション**：10,000ゲーム（シード固定）
- **E2E**：Playwright（再接続、ホスト移譲、カード非表示確認）

## 8. MVP範囲

含む：ルーム作成・10人参加・ゲーム進行・再接続・ホスト移譲・自動削除  
含まない：ユーザー登録・ランキング・チャット・公開マッチングなど
