# Wild Count カード構成（採用版）

本家をベースに少しアレンジした構成です。

## 総カード枚数：**54枚**

### 数字カード

| 値                     | 枚数 | 備考                      |
| ---------------------- | ---- | ------------------------- |
| +20                    | 1    | 高リスク高リターン        |
| +15                    | 2    |                           |
| +10                    | 3    |                           |
| +5                     | 4    |                           |
| +4                     | 4    |                           |
| +3                     | 4    |                           |
| +2                     | 4    |                           |
| +1                     | 4    |                           |
| 0                      | 3    | 通常0                     |
| **0 (捨て札ミックス)** | 1    | 特殊0（山札リセット効果） |
| -5                     | 2    |                           |
| -10                    | 1    |                           |

**数字カード小計：33枚**

### 特殊カード

| 種類         | 枚数 | 効果                |
| ------------ | ---- | ------------------- |
| x2 (DOUBLE)  | 1    | 合計値2倍           |
| MAX→0        | 1    | 最大値0化           |
| ? (引き直し) | 1    | 場に「？」で残る。チャレンジ後に山札から1枚オープン |

**特殊カード小計：3枚**

**総計：54枚**（調整可能）

---

## 特徴

- +20、+15を入れて派手さを追加（本家より少し攻撃的）
- 0のカードが多めで安全牌として機能
- 特殊カードは控えめ（合計3枚）で読み合いを重視
- 捨て札ミックス特殊0で山札リセット効果を残す
