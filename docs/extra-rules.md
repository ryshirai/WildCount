# Wild Count エクストラルール仕様

ホストがロビーで ON/OFF できる任意ルール。  
**デフォルトはすべて OFF**（現行 MVP と同一挙動）。

関連: `docs/game-rules.md` · `docs/card-design.md` · `docs/backlog.md`

---

## 1. 確定した共通方針

| 項目 | 決定 |
|------|------|
| 特殊能力 | セイム / チェンジ / リバース / ショット / ドロー1 / ダブル。UI 表記は **特殊能力** |
| アクション使用回数 | **1 ラウンド・1 人・1 回**（上記のいずれか 1 つを使ったら、そのラウンドは他の特殊能力も不可） |
| 宣言に乗せる能力 | リバース / ショット / ドロー1 / ダブルは **1 宣言につき最大 1 つ** |
| ラウンド跨ぎ | 次ラウンド開始で **使用権は全員復活** |
| セイム | 単独手。**個人アクション枠を 1 消費**。**直前がセイムなら連続不可**（別プレイヤー同士でも） |
| チェンジ | 単独手。**個人アクション枠を 1 消費** |
| ドロー1 だけ追加制限 | **ラウンド全体で 1 回**（誰かが使ったらそのラウンドは再使用不可） |
| ドロー対象 | **自分以外の生存者のみ** |
| 1/2 カード端数 | **0 方向の整数切り捨て**（`Math.trunc` 相当） |
| ダブルの名称 | 山札の ×2（DOUBLE）と区別せず UI でも **「ダブル」** でよい（文脈で分ける） |

### 手番の骨格（エクストラ ON 時）

```
自分の手番（通常）
  ├─ チャレンジ（直前宣言があるとき）※枠を消費しない
  ├─ セイム（直前宣言あり・枠あり・直前がセイムでない）
  ├─ チェンジ（直前宣言あり・枠あり）
  └─ 宣言
        └─ 任意で乗せる特殊能力を 1 つ（枠ありのとき）
              ├─ リバース
              ├─ ショット（次手番を指名）
              ├─ ドロー1（ラウンド全体 1 回・自分以外）
              └─ ダブル（次手番者がチャレンジしたらライフ −2）

強制再宣言（チェンジ後）
  └─ 宣言のみ（特殊能力・セイム・チャレンジ・チェンジ不可）
```

**個人アクション枠**を使うもの: **セイム** / **チェンジ** / リバース / ショット / ドロー1 / ダブル  

使える条件: **そのラウンドでまだ自分の個人アクション枠を使っていない**  
（ドロー1 はさらに **そのラウンドで未使用**）

## 2. 要素別仕様

### 2.1 1/2 カード（山札のみ・エクストラトグル対象外）

| 項目 | 内容 |
|------|------|
| 種類 | `half`（SPECIAL）。数値には寄与しない |
| 枚数 | **山札構成**（`specials.half`）。スタンダードは **0 枚**。ロビー山札カスタムで 0〜n |
| 効果 | 倍率 `× (1/2)^枚数` |
| 計算順 | MAX→0 → 数値合計 → **×2 と 1/2 をまとめて倍率** → **整数切り捨て（0 方向）** |
| 式 | `total = trunc( sum * (2 ** doubleCount) / (2 ** halfCount) )` |
| 例 | 合計 7・1/2×1 → 3。合計 −7・1/2×1 → −3。×2 と 1/2 各 1 → 打ち消し |

見え方: 他プレイヤーの額に「1/2」と表示（×2 と同型）。  
**ホストのエクストラルール ON/OFF には含めない**（山札パネルだけで制御）。

---

### 2.2 セイム（特殊能力・単独）

| 項目 | 内容 |
|------|------|
| 効果 | 現在の宣言値を維持したまま次手番へ（数値は上げない） |
| 条件 | フェーズ bidding・直前宣言あり・**個人枠あり**・**直前アクションがセイムでない** |
| 初手 | 宣言なしのラウンド開始時は不可 |
| 宣言同時 | 付けられない（宣言と同時ではない） |
| 回数 | **個人アクション枠を 1 消費**（他の特殊能力と共有）。連続セイムも禁止 |
| チャレンジ | セイム直後でも次手番者はチャレンジ可 |
| ダブル | セイムされた時点で `pendingLifeDouble` は **消滅** |

---

### 2.3 チェンジ（特殊能力・単独・個人枠消費）

| 項目 | 内容 |
|------|------|
| 効果 | **直前の宣言者**に、宣言値の付け直しを強制する |
| 条件 | 直前宣言あり・強制再宣言中でない・**個人アクション枠が残っている** |
| 消費 | 使用者の **個人アクション枠 1 回** |
| 宣言同時 | 付けられない（宣言と同時ではない） |
| ダブル | チェンジされた時点で `pendingLifeDouble` は **消滅**（次がチャレンジしなかった） |

#### 再宣言の合法値

直前宣言値を `B`、そのひとつ前の宣言値を `A` とする（初手宣言のときは `A` なし）。

| 状況 | 再宣言値 `x` の条件 |
|------|---------------------|
| `A` がある（例: 7→9） | 整数、`x > A`、**`x ≠ B`** |
| `A` がない（初手だけ） | 整数、`x ≥ minOpeningBid`、**`x ≠ B`** |

**例（ユーザー合意）**: 7 → 9 → チェンジ  
- `A=7`, `B=9`  
- 再宣言は **8** または **10 以上**（9 は不可。7 以下も不可）

#### 進行

1. プレイヤー C がチェンジを宣言する（C の手番を消費）
2. 手番は **直前宣言者 B** に移る（強制再宣言モード）
3. B は上記の合法値だけで `PLACE_BID`（**付随不可**）
4. `currentBid` / `currentBidderId` は B の新しい値に更新
5. **ひとつ前の値 `A` は維持**（捨てた `B` は履歴に残さない）  
   - 例: 7→9→チェンジ→8 のあと、さらにチェンジされたら `A=7`,`B=8` → 再々宣言は `x>7` かつ `x≠8`
6. 次の通常手番は **チェンジ使用者 C の次**（進行方向に沿った次の生存者）。B の再宣言の「次」ではない

#### 強制再宣言中にできないこと

- チャレンジ / セイム / チェンジ / 付随
- パス不可（必ず合法な再宣言を出す）

#### エッジ

| 状況 | 扱い |
|------|------|
| 生存 2 人 | 可。相手に付け直しさせる |
| 直前宣言者が切断・脱落 | チェンジ不可（または自動スキップ）。実装時は **合法手から除外** |
| 合法値が理論上ない | 整数で上に無限なので通常は発生しない（`A` ありなら `A+1` が `B` のとき `A+2` 等） |

---

### 2.4 リバース（宣言付随）

| 項目 | 内容 |
|------|------|
| 効果 | 席順の進行方向を反転（`turnDirection: 1 | -1`） |
| 次手番 | 反転後の「自分の隣」の生存者 |
| ラウンド開始 | 方向は **+1 にリセット** |
| 2 人 | 反転しても次が相手のまま（許容。無害） |
| 消費 | 自分の **個人アクション枠 1 回** |

---

### 2.5 ショット（宣言付随）

| 項目 | 内容 |
|------|------|
| 効果 | 次手番を **生存・自分以外** の 1 人に指名（1 回限り上書き） |
| 以降 | その次からは現在の `turnDirection` で通常進行 |
| 2 人 | 実質相手固定（許容） |
| 消費 | 自分の **個人アクション枠 1 回** |

---

### 2.6 ドロー1（宣言付随・ラウンド全体 1 回）

| 項目 | 内容 |
|------|------|
| 効果 | 指定した生存者に山札から **追加 1 枚** |
| 対象 | **自分以外**のみ |
| 回数 | **そのラウンドでテーブル全体 1 回**（誰かが使ったらそのラウンドは不可） |
| 復活 | 次ラウンドで再度 1 回まで可 |
| 手札 | 1 人複数枚あり得る → `hands: Record<Id, Card[]>` |
| 見え方 | コヨーテ式: 他人の全札は見える / 自分の札は枚数分 `?` |
| 特殊札 | 配札時ルールに準拠（`?` は引き直し、`zero_mix` はミックス等） |
| 消費 | 使用者の **個人アクション枠 1 回** も消費 |

合計: その人の全札が計算対象に含まれる。

---

### 2.7 ダブル（宣言付随・ライフ賭け）

※山札の ×2 カード（合計倍化）とは別物。UI 文言で文脈を分ける  
（例: 付随「ダブル」、札は「×2」のまま）。

| 項目 | 内容 |
|------|------|
| 効果 | **直後の手番者**がチャレンジした場合のみ、敗者ライフ **−2** |
| 消滅 | 直後がセイム / 宣言上げ / **チェンジ** ならフラグ消失（刺さらない） |
| 判定 | 勝敗は現行どおり `actual >= bid` → 宣言側勝ち。ダメージ量だけ 2 |
| ライフ不足 | ライフ 1 で −2 → 0 で脱落（オーバーキル可） |
| 消費 | 自分の **個人アクション枠 1 回** |
| ショット併用 | **不可**（付随は 1 つのみ）。「次」は通常隣 or リバース後の隣 |

## 3. 状態・設定（実装用スケッチ）

```ts
/** ロビー / GameConfig に載せるトグル（デフォルト false） */
interface ExtraRulesConfig {
  same: boolean          // セイム
  change: boolean        // チェンジ
  reverse: boolean       // リバース
  shot: boolean          // ショット
  draw1: boolean         // ドロー1
  lifeDouble: boolean    // ダブル（ライフ −2）
}
// 1/2 は ExtraRules ではなく DeckComposition.specials.half

// GameState 追記イメージ
turnDirection: 1 | -1
lastAction: 'bid' | 'same' | 'change' | 'challenge' | null
/** 現在宣言のひとつ前の値。チェンジ時の下限に使う。初手のみなら null */
bidUnderCurrent: number | null
/**
 * チェンジ後の強制再宣言中ならセット。
 * forbiddenValue = 捨てさせる値 B
 * minExclusive = A（なければ null → minOpeningBid 以上）
 */
pendingChangeRebid: {
  playerId: PlayerId
  forbiddenValue: number
  minExclusive: number | null
  /** 再宣言後に手番を渡す先（チェンジ使用者の「次」） */
  resumeNextPlayerId: PlayerId
} | null
/** このラウンドで個人アクション枠を使った playerId */
extraActionUsedThisRound: ReadonlySet<PlayerId>
/** このラウンドでドロー1が既に使われたか */
draw1UsedThisRound: boolean
/** 直前宣言にダブルが載っているか（次チャレンジで −2） */
pendingLifeDouble: boolean
hands: Readonly<Record<PlayerId, readonly Card[]>>  // 複数枚
```

アクション例:

```ts
| {
    type: 'PLACE_BID'
    value: number
    extra?:
      | { type: 'reverse' }
      | { type: 'shot'; targetId: PlayerId }
      | { type: 'draw1'; targetId: PlayerId }
      | { type: 'life_double' }
  }
| { type: 'SAME' }
| { type: 'CHANGE' }
```

強制再宣言中の `PLACE_BID` は `extra` 禁止。合法:

```ts
// minExclusive != null:
value > minExclusive && value !== forbiddenValue && Number.isInteger(value)
// minExclusive == null:
value >= minOpeningBid && value !== forbiddenValue && Number.isInteger(value)
```

## 4. 実装フェーズ

依存が少ない順。各フェーズは **単体テスト緑 + 既存パス非破壊（トグル OFF で現行と同一）** を受け入れ条件とする。

| Phase | ID | 内容 | 主な変更箇所 | 依存 |
|-------|-----|------|--------------|------|
| **E0** | ER-0 | 仕様固定・設定スケルトン | `ExtraRulesConfig` / `GameConfig` | — |
| **E1** | ER-1 | **1/2 カード**（山札） | `CardKind`・`deck`・`calculate`。**トグルなし** | E0 |
| **E2** | ER-2 | **セイム** | `SAME`・連続禁止 | E0 |
| **E3** | ER-3 | **リバース** + **個人アクション枠** | `turnDirection`・枠 Set | E0 |
| **E3b** | ER-3b | **チェンジ** | `CHANGE`・`bidUnderCurrent`・強制再宣言 | E3（枠）※E2 後が望ましい |
| **E4** | ER-4 | **ショット** | 次手番指名 | E3 |
| **E5** | ER-5 | **ダブル** | `pendingLifeDouble`・ライフ −2 | E3 |
| **E6** | ER-6 | **ドロー1** | 複数手札・ラウンド 1 回 | E3 |
| **E7** | ER-7 | ロビー UI・同期・ヘルプ | host トグル、WS | E1–E6 任意 |

### フェーズ詳細

#### E0 — スケルトン
- `ExtraRulesConfig` とデフォルト全 `false`（`change` 含む・`halfCard` は持たない）
- トグル OFF 時は既存テストがすべて通ることを固定

#### E1 — 1/2
- 計算・山札のみ。手番アクションなし
- 枚数は `specials.half`（山札カスタム）。エクストラトグルは設けない

#### E2 — セイム
- パス相当の最小追加
- `lastAction` で連続セイム禁止

#### E3 — リバース ＋ 個人アクション枠
- `extraActionUsedThisRound` を導入（付随とチェンジで共有）
- 宣言付随 API の形を固定

#### E3b — チェンジ
- `bidUnderCurrent` を通常宣言のたびに更新
- `CHANGE` → `pendingChangeRebid` → 強制 `PLACE_BID` → `resumeNextPlayerId` へ
- テスト: 7→9→チェンジ → 8 可・9 不可・10 可・7 不可
- テスト: 初手のみチェンジ → 同じ数字以外で `minOpeningBid` 以上
- セイムのあとのチェンジ可（宣言者は元の bidder のまま）

#### E4 — ショット / E5 — ダブル / E6 — ドロー1
- 従来どおり（E3 後）。ダブル消滅条件にチェンジを含める

#### E7 — プロダクト面
- ロビーチェックリストにチェンジを追加
- 強制再宣言中の UI（「付け直してください」「9 は不可」等）

### 推奨の切り出し順（実作業）

```
E0 → E1（独立）
   → E2（独立）
   → E3 → E3b（チェンジ）
       → E4 ∥ E5
       → E6
   → E7
```

E1 と E2 は並列可。E4/E5 は E3 後に並列可。E3b は E3 必須（枠共有）。

## 5. 明示的にやらないこと（この仕様の範囲外）

- パス（セイム以外の「何もしない」）
- 付随の複数同時
- ドロー1 の自己対象
- チェンジ再宣言への付随
- ジャストボーナス / チーム戦 / 点数制
- 合計 0 化カード（別 ticket）
- 本家 `?` のチャレンジ後入替タイミング変更

## 6. 受け入れチェック（全体）

- [ ] 全エクストラ OFF で現行と同一（回帰テスト）
- [ ] 1/2: 正負の切り捨て・×2 併用（山札枚数で制御）
- [ ] セイム: 連続不可・初手不可・個人枠消費
- [ ] 個人枠: 1 人 1 ラウンド 1 回（セイム・チェンジ・リバース・ショット・ドロー・ダブルで共有）、次ラウンドで復活
- [ ] チェンジ: 7→9→チェンジで 8 と 10+ のみ、同じ数字不可
- [ ] チェンジ後の次手番は使用者の次
- [ ] ショット: 自分以外のみ次手番
- [ ] ダブル: 次がチャレンジしたときだけ −2、セイム/上げ/チェンジで消滅
- [ ] ドロー1: ラウンド 1 回・自分以外・複数札が合計に入る
- [ ] online: 自分の札は送らない（複数枚でもマスク）
